## ✨ Features

- **🎬 8K UHD Video Downloads:** Lossless FFmpeg merging with support for **MP4** (universal compatibility), **MKV** (8K lossless), and **WEBM**.
- **🎵 High-Quality & Lossless Audio:** Download in **MP3 (320 kbps)**, **FLAC**, **M4A**, **OPUS**, and **WAV** with **automatically embedded album cover art and artist metadata**.
- **⚡ "Both at Once" Mode:** Download the video and extract a separate audio file in a single click.
- **📝 Playlists, Shorts & Subtitles:** Full support for YouTube videos, Shorts, and playlists, plus a one-click subtitle toggle.
- **📊 Pre-Download Size Estimate:** Displays the approximate file size before starting the download.
- **📂 Smart Folder Organization:** Automatically saves videos to `Videos > KozaFire` and music to `Music > KozaFire` (customizable anytime).
- **🖱️ Effortless Workflow:** Ad-free UI with drag-and-drop link support, `Ctrl+V` shortcut, and light/dark theme switching.

## 🚀 Installation & Usage

1. Go to the **[Releases](https://github.com/cagatay7753-pro/kozafire/releases)** page and download the latest `.msi` installer.
2. Double-click the `.msi` file to complete the setup (no ads, no bloatware).
3. Launch **KozaFire**, copy any YouTube video, Shorts, or playlist URL, and press `Ctrl+V` (or drag and drop the link into the window).
4. Choose **Audio / Music**, **Video**, or **Both**, select your format, and click **Download**.
